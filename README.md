# LangChain + Ollama Local AI Project

This is a beginner-friendly LangChain project that runs an AI model locally on your computer using Ollama.

The project uses the `llama3.2:3b` model through LangChain. It does not require an OpenAI, Gemini, or Claude API key, so you can test and learn without a paid API.

## Features

- Runs a local AI model with Ollama
- Uses LangChain to communicate with the model
- No paid API key required
- Uses Python virtual environment for clean dependency management

## Technologies Used

- Python 3.12
- LangChain
- LangChain Ollama
- Ollama
- Llama 3.2 3B model
